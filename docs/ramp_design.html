커브램프 재설계안 — 보도 절개형(Curb Cut)

현행 램프는 차도 위에 얹힌 웨지여서 차량 동선을 1.7 m 침범한다. 본 안은 램프를 보도 안쪽으로 옮긴다: 횡단보도와 같은 폭(4.0 m)으로 보도를 절개해 그 자리를 경사면으로 만들고, 양옆에 측면 플레어를 두어 어느 각도로 지나도 수직 단차 0 mm를 보장한다. rev.1은 보도 두께 1.5배(70→105 mm) 요구를 반영해 산정했고, v5.3 빌드로 시뮬레이션에 적용되었다.

01현행 문제 / 개선 개요 — 평면도

도면 1 — 평면도(발췌) · 축척 개념도램프는 보도 폭 3.0 m 안에서만 형성, 차도 침범 0

02단면 A–A (횡단 진행 방향)

도면 2 — 단면 A–A · 수직 8배 과장차도 → 램프(런 1.5 m) → 보도 통행대

03단면 B–B (연석선 방향, 플레어)

도면 3 — 단면 B–B(연석선 위치) · 수직 8배 과장플레어 단면은 보도 안쪽으로 갈수록 완화되어 램프 상단선에서 0 %

플레어는 뒤틀린 면(warped plane)이다: 연석선 위에서는 7.75 %로 기울지만, 램프 상단선(런 1.5 m 지점)에서는 보도와 같은 높이가 되어 경사 0 %로 수렴한다. 따라서 보도를 따라 걷다 절개부를 지나는 경로에도 계단형 단차가 전혀 없다.

06구현 (v5.3 빌드로 반영)

  1. 보도 슬래브 분할 — build_city.py에서 각 횡단보도 끝의 6.0 m 구간을 슬래브에서 제외하고 절개부 지오메트리로 대체.
  2. 본선 램프 — 검증된 box_mesh 피치 회전 방식(2.3°)으로 생성. 커스텀 웨지의 PhysX 쿠킹 실패 전력을 회피.
  3. 플레어 — 뒤틀린 면을 삼각형 2매(평면 보장)로 분할한 프리즘 메시. 면 와인딩(법선 상향)을 명시 검증.
  4. 레이아웃 반영 — city_layout.json의 ramps(why=crosswalk 28개)를 curb_cut 타입(폭 4.0·런 1.6·플레어 1.0)으로 갱신.
  5. 물리 검증 — /goto 낙하 z-안착 테스트(보도 0.297 기준) + 정면·종주·대각 3방향 연속 주행 + 렌더 확인.
